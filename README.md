# DroidX-Launcher-Releases.
Launcher Android com foco no modo desktop, janelas flutuantes e experiência semelhante a um PC. Compatibilidade otimizada para Galaxy Z Flip 5 e Z Flip 6. Outros dispositivos Samsung, Motorola, RedMagic e Xiaomi com suporte a janelas livres podem funcionar, mas precisam de testes. Projeto em fase beta.
